# Attribution & data licence

Health facility data from **healthsites.io** is published under the
**Open Database License (ODbL) v1.0** and is built on OpenStreetMap.

If you use this data, you must attribute it. Use the wording below.

## Required attribution

**Short form** (maps, app footers, tight UI):

> Health facility data: healthsites.io / © OpenStreetMap contributors (ODbL)

**Standard form** (about pages, documentation, reports):

> Health facility data sourced from [healthsites.io](https://healthsites.io),
> built on OpenStreetMap. © OpenStreetMap contributors.
> Licensed under the [Open Database License (ODbL) v1.0](https://opendatacommons.org/licenses/odbl/1-0/).

Keep the attribution visible wherever the data is shown to end users, and
keep any links live.

## Share-alike

ODbL is a share-alike licence. If you publicly use a **Derivative Database**
— for example by combining healthsites.io data with your own and publishing
the result — you must make that derivative database available under ODbL as
well. Producing a map, visualisation, or analysis *from* the data (a "Produced
Work") does not by itself trigger this, but the Produced Work must still carry
the attribution above.

Bulk or whole-country extracts count as a substantial part of the database,
so the share-alike terms apply to them. If you're unsure how this maps to your
product, get in touch and we'll work it out together.
